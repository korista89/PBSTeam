# 시트 운영 Apps Script (pbst_sheet_ops.gs)

사이트를 쓸 수 없을 때 담당자(운영 시트 편집자)가 운영 시트만으로 입력·확인한다. 사이트와 같은 원본 표에 쓴다.

## 설치 (한 번, 운영 시트 소유자)
1. 운영 시트 → [확장 프로그램] → [Apps Script]
2. 예전 `cico_auto_dropdowns`(월별 탭 드롭다운) 파일이 있으면 지운다(onEdit 이름이 겹침)
3. `pbst_sheet_ops.gs` 내용을 통째로 붙여 넣고 저장
4. 시트를 새로 고침 → 메뉴 [PBST → 처음 설정(한 번, 소유자)] → 권한 허용

## 쓰기
- 시트를 열면 보기 탭(CICO 입력·위기행동 보고서·학생 요약·차트)이 새로 만들어진다. 사이트 입력을 바로 보려면 [PBST → 지금 새로 고침]
- CICO 입력: 날짜 칸에 입력하면 바로 저장·수행률 계산(분포도 학생은 교시마다 한 줄)
- 위기행동 보고서: 흰 칸 작성·결재 체크 → Log_Main·Approvals에 바로 저장
- 차트: B3에서 학생을 고르면 차트가 바뀐다. 캡처해 담임에게 보낸다
- 행동 기록 입력은 구글 폼

계산이 사이트와 같은지는 `tests/test_apps_script_parity.py`가 검사한다.
