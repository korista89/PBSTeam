# 간헐 접속 실패 — 근본 대책 비교와 추천

작성: 2026-10-23 · 대상: https://pbs-team.vercel.app

## 결론 (먼저)

- **지금 할 일(0원):** 학교 PC 2~3대에 `접속 점검`을 1주일 돌려 **어느 단계에서 끊기는지** 확정한다.
- **동시에:** ③ 정보부 허용 요청 공문을 보낸다. 비용 0, 방화벽·DNS가 원인이면 효과가 가장 크다.
- **점검 결과가 DNS·연결 차단으로 나오면:** ① 사용자 지정 도메인을 붙인다(연 2만 원 안팎, 작업 30분). 기존 주소는 예비로 남긴다.
- ② Cloudflare 앞단, ④ 다른 호스팅 미러는 **추천하지 않는다.** 비용·관리 대비 효과가 ①보다 낮다.

---

## 확인된 사실 (2026-10-23)

- 실패는 **브라우저 연결 단계**에서 난다. 서버·로그인·Vercel 기록에 오류 0건.
- 같은 시각 다른 PC는 정상, 잠시 뒤 실패한 PC도 정상 → **서버 장애가 아니다.**
- `pbs-team.vercel.app` 은 요청마다 다른 IP(216.198.79.x, 64.29.17.x 등)로 응답한다.
  학교 보안장비가 IP·도메인 분류로 거르면 **어떤 IP는 통과하고 어떤 IP는 막히는** 간헐 현상이 생길 수 있다(가설, 점검으로 확인 필요).

## 접속 점검 (사이트 밖에서 기록)

**파일:** `scripts/net_probe.ps1` (학생 정보 없음, 관리자 권한 불필요)

### 하는 일

- 평일 07:30~17:30, 실행될 때마다 세 단계를 검사해 `pbst_netlog.csv` 에 한 줄 남긴다.
  1. DNS: 학교 DNS와 구글 DNS(8.8.8.8) 결과 비교
  2. TCP 443 연결(5초 제한)
  3. HTTPS `/api/health` 응답(20초 제한, Windows 내장 `curl.exe`)
- CSV는 엑셀에서 바로 열린다.

### 설치 (점검할 학교 PC에서, 교사가 직접)

1. `C:\pbst\` 폴더를 만들고 `net_probe.ps1` 을 넣는다.
2. 한 번 실행해 본다(PowerShell):
   ```powershell
   powershell -ExecutionPolicy Bypass -File C:\pbst\net_probe.ps1
   ```
3. 5분마다 자동 실행 등록(관리자 권한 불필요):
   ```powershell
   schtasks /Create /SC MINUTE /MO 5 /TN "PBST접속점검" /TR "powershell -NoProfile -ExecutionPolicy Bypass -WindowStyle Hidden -File C:\pbst\net_probe.ps1"
   ```
   - 실행 때 검은 창이 아주 잠깐 깜빡일 수 있다.
4. 결과 요약:
   ```powershell
   powershell -ExecutionPolicy Bypass -File C:\pbst\net_probe.ps1 -Summary
   ```
5. 끝나면 등록 해제:
   ```powershell
   schtasks /Delete /TN "PBST접속점검" /F
   ```

### 함께 하면 좋은 것 (선택)

- **학교 밖 감시:** UptimeRobot 같은 무료 감시 서비스에 `https://pbs-team.vercel.app/api/health` 를 5분 간격으로 등록하면,
  학교 PC가 실패한 시각에 서버는 정상이었는지 바로 비교된다(외부 계정 생성 필요).
- **교사 보고와 맞춰 보기:** 교사가 보낸 오류 시각과 CSV의 같은 시각 줄을 비교한다.

## 사이트 안 보조 개선 (적용됨)

- 조회·로그인 요청이 **응답 없음·502·504** 이면 1.5초, 3초 뒤 두 번 더 자동 재시도한다.
- 그래도 실패하면 화면 위에 "서버와 연결이 잠시 끊겼습니다 … F5" 안내를 띄운다.
- 구글 시트 읽기 한도(503)는 기존처럼 자동 재시도 + 안내한다.
- 한계: 페이지 자체가 열리지 않는 경우(`ERR_…` 화면)는 사이트 코드가 실행되기 전이라 도울 수 없다. 이 경우가 ①·③의 대상이다.
