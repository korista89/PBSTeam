# 공문(업무협조) 초안 — 학교행동지원 웹 플랫폼 접속 허용 요청

※ 수신·발신 부서명과 담당자는 학교 실정에 맞게 고쳐 쓴다. 붙임 자료는 접속 점검 1주일 뒤 첨부한다.

---

**수신** 정보부장(정보 담당)
**(경유)**
**제목** 학교행동지원 웹 플랫폼 접속 안정화를 위한 네트워크 예외 등록 협조 요청

1. 관련: 2026학년도 경은학교 긍정적 행동지원(SW-PBS) 운영계획

2. 우리 학교 학교행동중재지원팀이 위기행동 기록과 보고서 결재에 사용하는 웹 플랫폼이 교내 일부 PC에서 간헐적으로 접속되지 않아, 네트워크 예외 등록을 아래와 같이 협조 요청하고자 합니다.

   가. 현황
      1) 증상: 교내 일부 PC에서 '사이트에 연결할 수 없음'이 간헐적으로 발생하고, 새로고침하면 접속됨
      2) 확인 결과: 같은 시각 다른 PC와 학교 밖에서는 정상이며, 서버 오류 기록은 없음
      3) 영향: 위기행동 발생 직후 학교장 보고·보호자 알림 기록이 늦어질 수 있음

   나. 요청 사항
      1) 아래 주소를 유해사이트 차단·방화벽 정책의 허용 목록에 등록
         가) pbs-team.vercel.app (HTTPS, 443 포트)
         나) *.vercel.app (주소 변경에 대비한 예비 등록, 가능한 경우)
      2) 학교 DNS에서 위 주소의 조회 실패 기록이 있는지 확인
      3) SSL 검사(암호화 통신 검사) 장비가 있으면 위 주소를 검사 예외로 등록

   다. 참고 사항
      1) 플랫폼에는 학생 실명 대신 가림 이름(예: 김O준)과 학생코드만 저장함
      2) 접속 점검 기록(시각별 성공·실패, 실패 단계)을 붙임으로 제공함
      3) 사용자 지정 도메인을 추가할 경우 해당 주소를 다시 알려 드림

붙임  1. 교내 PC 접속 점검 기록(1주일) 1부.
      2. 접속 오류 발생 현황(교사 보고) 1부.  끝.
