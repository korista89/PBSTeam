# 경은PBST 접속이 안 될 때 (교사용 1쪽)

**주소:** https://pbs-team.vercel.app

> **먼저 이것만:** 쓰던 내용은 지워지지 않습니다.
> **1분 기다렸다가 F5(새로고침)** 를 누르세요. 대부분 이걸로 됩니다.

---

## 1. 화면 아래 회색 글자(오류 코드)를 확인하세요

"사이트에 연결할 수 없음" 화면 아래쪽에 `ERR_…` 글자가 있습니다.
**사진을 찍거나 받아 적어** 담당자(교무기획부)에게 보내 주세요. 원인을 찾는 데 가장 중요합니다.

| 오류 코드 | 뜻 | 이렇게 하세요 |
|---|---|---|
| `ERR_NAME_NOT_RESOLVED`<br>`DNS_PROBE_FINISHED_…` | 주소를 찾지 못함(학교 DNS) | 1분 뒤 새로고침 → 안 되면 **2번 방법** |
| `ERR_CONNECTION_TIMED_OUT`<br>`ERR_TIMED_OUT` | 연결이 너무 오래 걸림 | 1분 뒤 새로고침 → 다른 사이트도 느리면 망 문제 |
| `ERR_CONNECTION_RESET`<br>`ERR_CONNECTION_CLOSED` | 중간에서 연결이 끊김(학교 보안장비 가능성) | 새로고침 → 반복되면 **시각과 함께** 담당자에게 |
| `ERR_INTERNET_DISCONNECTED`<br>`ERR_NETWORK_CHANGED` | 이 PC의 인터넷이 잠깐 끊김 | 랜선·와이파이 확인 후 새로고침 |
| `ERR_SSL_PROTOCOL_ERROR`<br>`ERR_CERT_…` | 보안 연결 실패 | PC 날짜·시각이 맞는지 확인 → 담당자에게 |
| 사이트 안에 "서버와 연결이 잠시 끊겼습니다" | 사이트가 3번 다시 시도했지만 실패 | 잠시 뒤 다시 누르기 → 계속되면 F5 |
| 사이트 안에 "구글 시트 응답이 지연" | 자료 창고(구글 시트)가 잠깐 바쁨 | 기다리면 저절로 다시 불러옵니다 |

## 2. 그래도 안 되면 (순서대로)

1. **다른 브라우저로 열기**
   - 크롬이 안 되면 **엣지(Edge)**, 엣지가 안 되면 크롬.
2. **옆 PC나 휴대폰(데이터)으로 열어 보기**
   - 휴대폰에서는 되는데 PC만 안 되면 → 학교망 문제입니다. 담당자에게 알려 주세요.
3. **크롬 '보안 DNS' 켜기** (관리자 권한 없이 가능, 정보부 안내에 따름)
   - 주소창에 `chrome://settings/security` 입력
   - **보안 DNS 사용** 켜기 → 서비스 **Google(공개 DNS)** 선택
   - `ERR_NAME_NOT_RESOLVED` 가 자주 날 때만 씁니다.
4. **급한 보고서는 종이로**
   - 사이트의 '빈 양식(hwpx)'을 미리 출력해 두고 손으로 쓴 뒤, 접속되면 입력합니다.

## 3. 담당자에게 보낼 내용 (복사해서 채우기)

```
[PBST 접속 오류]
- 시각: 2026. 10. 23. 10:35
- 교실/PC: 3층 ○○반 교사용 PC
- 오류 코드: ERR_……
- 새로고침 뒤: 됨 / 안 됨
- 휴대폰(데이터)에서는: 됨 / 안 됨 / 안 해 봄
```

※ PC의 네트워크 설정(DNS 주소 변경 등)은 학교 정보부 확인 없이 바꾸지 않습니다.
