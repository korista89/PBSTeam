# 경은PBS 인수인계 자료 (이전 학년도 기록 연계)

## 원칙
- 사이트(Google Sheets·Vercel)에는 **이전 학년도 원자료를 두지 않는다.** 해킹되어도 원자료가 나가지 않게 하기 위함이다.
- 개인정보 제공 동의 효력은 2026. 3. 2. ~ 2027. 2. 28.이다. 이 기간의 2026학년도 기록은 사이트에서 그대로 활용한다.
- 인수인계 파일은 **비식별(가명 ID P+영문 6자)** 이며, 학교가 관리하는 저장소(내 드라이브·학교 PC)에만 둔다. 메신저·외부 서버에 올리지 않는다.
- 연결표(학생코드 ↔ 가명 ID)는 개인정보로 취급한다. 연결 권한은 관리자만 가진다.

## 전임자가 하는 일 (2027년 2월 마감 때)
1. `cd backend && .venv/bin/python ../scripts/build_year_archive.py --final --handover`
   - `~/data/archive/` 에 `2026학년도 경은PBS 데이터.csv`(최종)와 `경은PBS 인수인계 자료(2024~2026학년도).json` 이 생긴다.
   - 이전 학년도(2024·2025)는 같은 폴더의 CSV에서 가져오므로 CSV를 지우지 않는다. 가명 키 `~/data/private/archive_key` 도 같은 학생이 같은 ID를 갖도록 보관한다.
2. 마감 뒤 시트 원자료 폐기: `python ../scripts/retire_prior_years.py --year 2026 --apply`
   (백업은 `~/data/private/` 에 남으므로 사이트 밖 안전한 곳으로 옮긴다.)
3. 인수인계 `.json` 을 다음 담당자에게 학교 관리 저장소로 전달한다.

## 후임자가 하는 일 (2027학년도 운영 전)
1. 사이트 **Tier 현황 → 📎 인수인계 연결** 에서 `.json` 을 고른다(브라우저에서만 읽음).
2. 학생별로 목록에서 그 학생으로 보이는 ID를 고른다(학년도별 건수·주요 행동유형·강도 표시). 담임에게 확인한다.
3. 연결한 학생은 **학생 개별 대시보드 → 🗂️ 과거 학년도 비교** 에서 같은 `.json` 을 고르면 학년도·월별로 올해와 비교된다.
